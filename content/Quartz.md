# Quartz

## 한 줄 정의
Obsidian 위키 마크다운 노트들을 인터랙티브 정적 웹사이트로 변환해 주는 TypeScript 기반 정적 사이트 생성기(SSG).

## 핵심 요지
- **Obsidian 호환성**: 위키링크(`노트`), 백링크, 태그, 다크모드, 그래프 뷰 지원.
- **GitHub Pages 배포**: Node.js v22 환경 및 GitHub Actions CI/CD를 통한 무료 호스팅.
