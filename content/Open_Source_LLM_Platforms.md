## 한 줄 정의
로컬 셀프 호스팅부터 고속 클라우드 API까지, 2026년 기준 실무에서 활용 가능한 오픈소스 LLM 플랫폼 비교 및 구축 가이드입니다.

## 핵심 요지
- **플랫폼 다각화:** Ollama(로컬), OpenRouter(게이트웨이), Groq(속도), [[NVIDIA NIM]](도메인 특화) 등 용도별로 다양한 플랫폼이 존재합니다.
- **호환성 최적화:** 거의 모든 오픈소스 플랫폼이 OpenAI API 호환 규격을 사용하여 서비스 간 전환이 용이합니다.
- **무료 스택 전략:** 여러 플랫폼의 무료 호출 한도를 조합하여 하루 300만~400만 토큰 이상을 무료로 활용 가능합니다.
- **아키텍처 유연성:** 환경 설정(환경 변수)만으로 로컬 개발 환경에서 프로덕션 운영 환경으로 즉각 전환 가능한 설계가 필요합니다.

## 상세
2026년 현재 오픈소스 모델은 성능 면에서 폐쇄형 모델과 대등합니다. 실무 도입 시 고려할 핵심 플랫폼은 다음과 같습니다.
- **Ollama:** 데이터 보안과 프라이버시가 중요한 로컬 개발 환경에 적합합니다.
- **OpenRouter:** 모델 평가, A/B 테스트, 단일 API로 수백 개 모델을 관리할 때 유리합니다.
- **Groq:** LPU 인프라를 통해 타 플랫폼 대비 3~7배 빠른 초저지연 성능을 제공합니다.
- **[[NVIDIA NIM]]:** 생물학, 화학 등 도메인 특화 모델과 안전성 강화(Guardrails) 모델이 강점입니다.

## 예시
- **하이브리드 패턴:** 개발은 로컬 Ollama, 테스트는 OpenRouter의 무료 모델, 운영은 Groq의 고속 엔드포인트를 사용하여 인프라 전환 비용을 최소화합니다.
