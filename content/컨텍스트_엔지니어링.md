## 한 줄 정의
AI 에이전트가 각 작업 단계(Turn/Node)에서 필요한 정보를 적시에, 적절한 형식으로, 최적화된 상태(압축/정리)로 제공하는 시스템 설계 규율.

## 핵심 요지
복잡한 멀티 에이전트 시스템에서 에이전트가 실패하는 주된 원인은 추론 능력 부족이 아니라, 단계 간의 잘못된 정보 전달(Context Handoff)이다. Prompt Engineering이 질문을 다듬는 기술이라면, [[Context Engineering]]은 질문이 해결되는 '환경(조건)'을 설계하는 기술이다.

## 상세
- **Context 3층 구조**: 
    1. **Persistent Context**: 사용자 목표, 도메인 규칙 등 항상 유지되어야 하는 기본 맥락.
    2. **Time-sensitive Context**: 검색 결과, API 응답 등 단계별로 갱신되는 맥락(RAG 핵심).
    3. **Transient Context**: 중간 연산 결과, 원시 API 페이로드 등 단계 종료 후 즉시 폐기해야 하는 맥락(Attention 경쟁 방지).
- **Context Routing**: 모든 정보를 모든 에이전트에게 전달하는 대신, 작업 수행에 필요한 정보만 선별적으로 전달하는 데이터 라우팅 필요 [raw/AI 에이전트에게 Prompt Engineering은 죽었다. 이제 진짜 중요한 것은 [[Context Engineering]]이다.md#L96](file:///Users/railscraft/Obsidian/raw/AI%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%EC%97%90%EA%B2%8C%20Prompt%20Engineering%EC%9D%80%20%EC%A3%BD%EC%97%88%EB%8B%A4.%20%EC%9D%B4%EC%A0%9C%20%EC%A7%84%EC%A7%9C%20%EC%A4%91%EC%9A%94%ED%95%9C%20%EA%B2%83%EC%9D%80%20Context%20Engineering%EC%9D%B4%EB%8B%A4.md#L96).
- **상태 관리(State as Contract)**: 에이전트 간 전달되는 `AgentState`를 단순 메모장이 아닌 엄격한 계약(TypedDict)으로 관리하여 누락과 환각 방지.

## 예시
LangGraph 에이전트 설계 시 `TypedDict`를 활용하여 persistent, time-sensitive, transient 데이터를 구분하여 정의 [raw/AI 에이전트에게 Prompt Engineering은 죽었다. 이제 진짜 중요한 것은 [[Context Engineering]]이다.md#L76](file:///Users/railscraft/Obsidian/raw/AI%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%EC%97%90%EA%B2%8C%20Prompt%20Engineering%EC%9D%80%20%EC%A3%BD%EC%97%88%EB%8B%A4.%20%EC%9D%B4%EC%A0%9C%20%EC%A7%84%EC%A7%9C%20%EC%A4%91%EC%9A%94%ED%95%9C%20%EA%B2%83%EC%9D%80%20Context%20Engineering%EC%9D%B4%EB%8B%A4.md#L76).

## 충돌
단순히 context window를 키우는 것은 근본 해결책이 아니며, 잘못된 정보(Stale Context)를 넘기는 것은 없는 것보다 훨씬 위험함 [raw/AI 에이전트에게 Prompt Engineering은 죽었다. 이제 진짜 중요한 것은 [[Context Engineering]]이다.md#L108](file:///Users/railscraft/Obsidian/raw/AI%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%EC%97%90%EA%B2%8C%20Prompt%20Engineering%EC%9D%80%20%EC%A3%BD%EC%97%88%EB%8B%A4.%20%EC%9D%B4%EC%A0%9C%20%EC%A7%84%EC%A7%9C%20%EC%A4%91%EC%9A%94%ED%95%9C%20%EA%B2%83%EC%9D%80%20Context%20Engineering%EC%9D%B4%EB%8B%A4.md#L108).
