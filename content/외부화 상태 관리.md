### 🔑 주요 수록 내용 요약

1. **한 줄 정의**: LLM의 휘발성 [[context window]] 대신 Git 저장소 및 구조화된 파일 시스템에 에이전트 상태와 의사결정을 지속적으로 기록해 장기 실행 에이전트의 지속성(durability)을 보장하는 패턴.
2. **핵심 요지**:
   - Context Window를 손실 발생 캐시로 규정하고 참 진실(Single Source of Truth)을 외부 스토리지로 격리.
   - 프로세스 재부팅, OS 패치, context window 초과 등의 중단을 정상 이벤트로 흡수(`Embrace Disruption`).
   - 결정적 자동화 검증 통과 시에만 단일 Git 커밋으로 묶는 원자적 체크포인트 기법.
   - 수 밀리초 만에 이전 진행 상황을 완벽히 복원하는 상황 인식 재구축 스냅샷 (`SituationSnapshot`).
3. **상세 기술 메커니즘**:
   - `checklist.json`, `decisions.jsonl`, `events.jsonl` 데이터 스키마 명세 및 역할 정의.
   - Temporal 기반 비결정적 연산(Activity) 저널링과 스케줄러(Workflow) Replay를 결합한 불시 재부팅 복구.
4. **구체적 예시 및 코드/수치**:
   - Pydantic 기반 체크리스트 데이터 모델 코드 예시 포함.
   - 파이썬 LSP 서버 7일 구축 과제(`lra`) 실증 지표 수록: 총 615 사이클, $178.60 소모 (`claude-opus-4-8`, `claude-haiku-4-5-20251001`, `ollama` 사용 등).
