## 한 줄 정의
실시간 아티팩트(Live Artifact)는 정적인 문서 뷰를 넘어, 에이전트 런타임이 백그라운드 API 및 로컬 디렉토리를 지속적으로 다시 긁어와 화면 데이터를 역동적으로 갱신하는 양방향 대화형 위젯 모듈이다.

## 핵심 요지
- 정적 스냅샷 파일 저장 방식과 달리, 창을 열 때마다 메일 히스토리나 로컬 변경점을 자동으로 동기화하여 실시간 정보의 일관성을 맞춘다 [raw/지루한 업무를 자동화하는 [[클로드 코워크]] 프롬프트 7가지.md#L101](file:///Users/railscraft/Obsidian/raw/%EC%A7%80%EB%A3%A8%ED%95%9C%20%EC%97%85%EB%AC%B4%EB%A5%BC%20%EC%9E%90%EB%8F%99%ED%99%94%ED%95%98%EB%8A%94%20%ED%81%B4%EB%A1%9C%EB%93%9C%20%EC%BD%94%EC%9B%8C%ED%81%AC%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8%207%EA%B0%80%EC%A7%80.md#L101).
- 별도의 캐시를 남기지 않으므로, 정보 노출이나 동기화 불일치 문제가 발생할 리스크를 극소화한다.

## 상세
- **실시간 바인딩**: 실시간 아티팩트는 [[클로드 코워크]] 등에서 활용된다. 프롬프트 선언 시 `실시간 아티팩트로 빌드해 줘` 혹은 `이전 상태를 캐싱하지 마`라는 지시문을 추가하여 구현된다 [raw/지루한 업무를 자동화하는 [[클로드 코워크]] 프롬프트 7가지.md#L90-L95](file:///Users/railscraft/Obsidian/raw/%EC%A7%80%EB%A3%A8%ED%95%9C%20%EC%97%85%EB%AC%B4%EB%A5%BC%20%EC%9E%90%EB%8F%99%ED%99%94%ED%95%98%EB%8A%94%20%ED%81%B4%EB%A1%9C%EB%93%9C%20%EC%BD%94%EC%9B%8C%ED%81%AC%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8%207%EA%B0%80%EC%A7%80.md#L90-L95).
- UI 내에서 새로고침(Reload) 버튼을 제공해 즉석에서 받은 편지함 스캔을 유도하는 등 강력한 액티브 대시보드로 기여한다 [raw/지루한 업무를 자동화하는 [[클로드 코워크]] 프롬프트 7가지.md#L101](file:///Users/railscraft/Obsidian/raw/%EC%A7%80%EB%A3%A8%ED%95%9C%20%EC%97%85%EB%AC%B4%EB%A5%BC%20%EC%9E%90%EB%8F%99%ED%99%94%ED%95%98%EB%8A%94%20%ED%81%B4%EB%A1%9C%EB%93%9C%20%EC%BD%94%EC%9B%8C%ED%81%AC%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8%207%EA%B0%80%EC%A7%80.md#L101).

## 예시
- **입사 지원 현황 대시보드**: Gmail 필터를 활용해 `application received`, `interview` 등 구직 관련 메일 히스토리를 재스캔하여 지원 상태와 마지막 연락일을 업데이트하는 실시간 아티팩트 구현 [raw/지루한 업무를 자동화하는 [[클로드 코워크]] 프롬프트 7가지.md#L358-L383](file:///Users/railscraft/Obsidian/raw/%EC%A7%80%EB%A3%A8%ED%95%9C%20%EC%97%85%EB%AC%B4%EB%A5%BC%20%EC%9E%90%EB%8F%99%ED%99%94%ED%95%98%EB%8A%94%20%ED%81%B4%EB%A1%9C%EB%93%9C%20%EC%BD%94%EC%9B%8C%ED%81%AC%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8%207%EA%B0%80%EC%A7%80.md#L358-L383).

## 충돌
- 데이터 갱신 시 외부 벤더 API 레이트 리밋에 걸릴 수 있으며, 런타임 성능 상실의 원인이 되기도 하므로 스케줄링 간격 설정 시 적절한 트레이드오프가 요구된다.
