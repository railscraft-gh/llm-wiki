# 모라벡의 역설

## 한 줄 정의

모라벡의 역설(Moravec's Paradox)은 인간에게 고도의 논리적 추론이 요구되는 연산, 체스, 어려운 시험 패스 등은 컴퓨터에게 쉬운 반면, 인간에게 지극히 사소하고 본능적인 물리적 신체 조작(예: 컵 쥐기, 장애물 피하며 걷기 등)은 기계에게 극도로 어렵다는 공학적 역설이다.

## 핵심 요지

- **역설적 지능 난이도**: 1988년 로봇공학자 한스 모라벡(Hans Moravec)이 제기한 법칙으로, 지능의 난이도에 대한 생물학적 직관과 컴퓨터 공학적 구현 난이도가 완전히 모순됨을 보여준다 (raw/ChatGPT보다 세상을 더 잘 이해하는 당신의 고양이, 그리고 이것 때문에 메타를 그만둔 AI 대부 중 한 명-ko.md).
- **[[LLM]] 지능의 착시**: 얀 르쿤 교수는 이 역설로 인해 현 [[LLM]]이 실제 지능의 체급보다 훨씬 똑똑하게 포장되어 대중에게 인지적 착시를 일으킨다고 지적한다 (raw/ChatGPT보다 세상을 더 잘 이해하는 당신의 고양이, 그리고 이것 때문에 메타를 그만둔 AI 대부 중 한 명-ko.md).
- **수억 년의 진화적 산물**: 기호 계산이나 언어적 조립은 인류 역사에서 비교적 최근에 발달한 단순 규칙이므로 기계 모방이 쉽지만, 시공간을 유연하게 대처하며 움직이는 신체 지능은 생명체가 수억 년의 진화를 통해 세포 깊숙이 누적해 다져온 고도의 물리학 연산이기에 구현이 매우 어렵다.
- **세계 접촉의 결여**: 네 살배기 아이가 4년간 세상을 둘러보며 시각으로 받아들이는 원시 정보량이 인류가 디지털화한 모든 텍스트 학습량을 압도함에도, 현재의 LLM은 시공간 실체와의 직접적인 접촉 없이 단어 예측만 수행하므로 근본적인 지능 구현에 한계를 가진다 (raw/ChatGPT보다 세상을 더 잘 이해하는 당신의 고양이, 그리고 이것 때문에 메타를 그만둔 AI 대부 중 한 명-ko.md).

## 상세

모라벡의 역설은 AI의 똑똑함이 어디에 정의되는지 묻는 지능의 기준을 크게 뒤집어 놓는다. 

인간의 사회적 위계 속에서는 미적분을 풀거나 바둑 챔피언이 되는 것이 청소나 식기세척기 정리보다 지적으로 높은 대우를 받는다. 그러나 인공지능 공학적 관점에서는 수만 가지 변수가 뒤엉킨 지저분한 방 안을 스스로 움직여 장애물을 치우는 청소부의 유연한 피드백 대처 능력이 바둑을 두는 알고리즘보다 수백 배는 더 정교하고 어렵다. 

현대 대중들이 [[LLM]] 챗봇이 논문을 쓰고 변호사 시험을 1등으로 통과하는 것을 보며 '초지능'이라 경외를 표하지만, 정작 이 기계들은 식기세척기 그릇 하나 제대로 배치하지 못하는 외골수 상태에 머물러 있다. 창턱에 사뿐히 뛰어내려 착지하는 고양이는 지구상의 어떤 AI 슈퍼컴퓨터로도 실시간 계산하기 어려운 복잡한 다물체 동역학 및 마찰력 시뮬레이션을 온몸으로 실행해내는 진정한 [[세계 모델]] 지능의 완성체다.

이 역설을 극복하기 위해 얀 르쿤(Yann LeCun) 교수는 픽셀 단위 예측 대신 고차원 잠재 공간(Latent Space)에서 의미론적 개념 단위로 미래 상태를 예측하는 [[JEPA]] (Joint Embedding Predictive Architecture) 및 [[V-JEPA 2]] 아키텍처를 제시했다. [[V-JEPA 2]]는 라벨링 없는 100만 시간의 비디오 관찰 학습 후 단 62시간 미만의 로봇 작동 데이터 연동만으로 미지의 환경에서 로봇 팔 조작을 성공시켰다 (raw/ChatGPT보다 세상을 더 잘 이해하는 당신의 고양이, 그리고 이것 때문에 메타를 그만둔 AI 대부 중 한 명-ko.md). 또한 페이페이 리(Fei-Fei Li) 교수는 언어 이전에 공간 인지가 인간 사고의 뼈대 역할을 한다는 [[공간 지능]] 개념을 제안하며, 3차원 세상을 즉석 렌더링하는 [[Marble]] 모델을 공개하는 등 모라벡의 역설을 풀기 위한 시공간 표현 모델링 시도가 이어지고 있다 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md).

## 예시

- **바둑 vs 가사 노동**: 바둑을 학습해 세계 챔피언을 꺾는 프로그램은 2016년에 이미 완성되었으나, 젖은 빨래를 널거나 애호박의 껍질을 깎고 방을 치우는 로봇은 2026년 현재에도 상업적으로 완성도 높은 구현이 매우 어렵고 제한된 시연 단계에 머물고 있다.
- **고양이의 점프**: 보상 함수나 추가 데이터 센터 인프라 없이도, 미끄러운 바닥 상태와 뛰어넘을 가구 틈을 순간적으로 인지하고 단 한 번의 몸놀림으로 가뿐히 뛰어넘는 지능의 실현.
- **LLM 대 세계 모델(JEPA)의 예측 메커니즘 차이**:
  다음 단어(Next-Token)를 추측하는 [[LLM]] 방식과 잠재 임베딩 공간에서 픽셀 노이즈를 제거하고 미래 개념 상태를 예측하는 [[JEPA]] 방식의 모듈 구조 비교 예시:

```python
import torch
import torch.nn as nn

# 1. LLM 방식: Next-Token Prediction (단어 확률 분포 예측)
class NextTokenLLM(nn.Module):
    def __init__(self, vocab_size=50000, embed_dim=768):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.transformer_block = nn.TransformerEncoderLayer(d_model=embed_dim, nhead=8)
        self.lm_head = nn.Linear(embed_dim, vocab_size)

    def forward(self, token_ids):
        # x: (seq_len, batch_size, embed_dim)
        x = self.embedding(token_ids)
        feat = self.transformer_block(x)
        logits = self.lm_head(feat[-1]) # 다음 단어 확률 (5만개 어휘 중 선택)
        return logits

# 2. 세계 모델 (JEPA) 방식: Latent Concept Prediction (의미 공간 상의 미래 상태 예측)
class WorldModelJEPA(nn.Module):
    def __init__(self, latent_dim=512):
        super().__init__()
        # 픽셀 노이즈를 제거하고 고차원 시공간 개념으로 압축하는 시각 인코더
        self.context_encoder = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=4, stride=2),
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
            nn.Linear(64, latent_dim)
        )
        # 잠재 공간 상에서 미래 행동/상태 변화를 예측하는 시뮬레이터
        self.predictor = nn.Sequential(
            nn.Linear(latent_dim + 32, latent_dim), # 현재 잠재 상태 + 로봇 액션
            nn.ReLU(),
            nn.Linear(latent_dim, latent_dim) # 미래 프레임의 잠재 표현(Latent State) 예측
        )

    def forward(self, current_frame, action_vector):
        s_t = self.context_encoder(current_frame) # s_t: 고차원 물리 상태 표현
        s_t_plus_1_pred = self.predictor(torch.cat([s_t, action_vector], dim=-1))
        return s_t_plus_1_pred
```

- **Physical Intelligence vs V-JEPA 2 시연**: 스타트업 Physical Intelligence의 [[VLA]] (Vision-Language-Action) 모델 기반 로봇은 애호박 껍질을 깎고 바람개비를 접는 고난도 조작을 시연했으나 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md), 르쿤 교수의 계층형 [[세계 모델]] 로봇은 현실 오차가 누적되기 전 단 5단계 앞선 미래 예측 수준에서 상위 계획과 하위 단기 보정을 조율하는 실현 단계에 있다 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md).

## 충돌

- **스케일업(LLM/VLA) 진영 대 세계 모델(JEPA/공간 지능) 진영의 정답 대립**:
  - **스케일업 파벌 주장**: 리처드 서튼의 '쓰라린 교훈(The Bitter Lesson)'에 기반하여, 우아한 수작업 알고리즘이나 인지 구조 설계보다 무작정 규모(Compute & Data)를 확장한 투박한 모델이 언제나 승리해왔다고 본다 (raw/ChatGPT보다 세상을 더 잘 이해하는 당신의 고양이, 그리고 이것 때문에 메타를 그만둔 AI 대부 중 한 명-ko.md). Physical Intelligence의 [[VLA]] 모델처럼 LLM 기반 로봇이 현재 애호박 껍질 벗기기, 종이접기 등 고난도 조작을 압도적 성능으로 시연하고 있어 당장의 실무적 정답은 스케일링이라고 주장한다 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md).
  - **세계 모델 파벌 주장**: 얀 르쿤과 리처드 서튼 모두 텍스트 모방에만 의존하는 LLM 스케일업은 현실 시공간과의 직접적 접촉이 결여되어 진정한 지능으로 가는 '막다른 골목(Dead End)'이라 지적한다 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md). 현재 세계 모델 기반 로봇(V-JEPA 2)이 컵 하나 밀어내는 데 60초가 걸릴 정도로 초라할지라도 (1995년의 신경망 초기 상태와 유사), 물리적 세계의 인과관계를 예측하는 내부 지도를 구축하는 것만이 모라벡의 역설을 근본적으로 극복하는 유일한 길이라고 주장한다 (raw/당신의 고양이가 챗GPT보다 세상을 더 잘 이해하는 이유.md).
