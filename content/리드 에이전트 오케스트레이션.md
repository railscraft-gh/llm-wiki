  2. **핵심 요지**: 단일 지휘소 통합 조율, 리드 에이전트 맥락(Context Window) 오염 방지, 원자적 작업 해체(Atomic Decomposition), 검증 훅(`SubagentStop`) 및 Grader 연동, 최적 병렬 가동 규모(3~5개) 준수 (`raw/0xMorty_Loop_Design.md`).

  4. **예시**: TypeScript 기반 `LeadAgentOrchestrator` 클래스 구현 코드 및 `Claude 3.7 Sonnet` 모델을 활용한 대규모 REST API → GraphQL 마이그레이션 실무 시나리오 제공.
  5. **충돌**: 완전 자율 병렬 스웜(속도 우수, 머지 지옥 및 맥락 덮어쓰기 발생 위험)과 엄격한 리드 통제(안전성 최고, 서브 에이전트 대수 증가 시 리드의 Context Window 병목 가능성) 간의 기술적 트레이드오프 분석.
