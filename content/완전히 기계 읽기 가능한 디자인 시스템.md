# 완전히 기계 읽기 가능한 디자인 시스템

## 한 줄 정의

완전히 기계 읽기 가능한 디자인 시스템은 AI 에이전트가 코드를 작성할 때 디자인 시스템의 Foundations(기초 규칙)와 Component specs(컴포넌트 규격)를 맥락에 맞춰 올바르게 적용하도록 설계한 계층화된 맥락 시스템(layered context system)이다.

## 핵심 요지

- **MCP의 한계 극복**: 모델 컨텍스트 프로토콜(MCP)은 요청 기반(On-demand)으로 작동하여 컴포넌트 API 명세는 제공하지만, 간격 문법, 타이포그래피 계층 등 명시적으로 요청하지 않은 기초 지식(Foundations)은 누락되어 디자인 일관성 붕괴(Style drift)를 초래한다 [완전히 기계 읽기 가능한 디자인 시스템-ko.md](../raw/%EC%99%84%EC%A0%84%ED%9E%88%20%EA%B8%B0%EA%B3%84%20%EC%9D%BD%EA%B8%B0%20%EA%B0%80%EB%8A%A5%ED%95%9C%20%EB%94%94%EC%9E%90%EC%9D%B8%20%EC%8B%9C%EC%8A%A4%ED%85%9C-ko.md).
- **점진적 맥락 공개(Progressive Context Disclosure)**: 디자인 규격을 단일 `DESIGN.md` 파일에 밀어 넣는 대단위 주입 방식은 토큰 과부하를 일으키므로, 지식 레이어를 다단으로 분절하고 이를 색인하는 단 하나의 스킬(`SKILL.md`)을 두어 에이전트가 상황에 맞는 레이어를 순차적으로 로드하게 한다.
- **검증(Validation)과 학습(Training)의 분리**: MCP가 현재 컴포넌트의 사실관계를 검증(Card, Button, props 반환 등)한다면, 컨텍스트 플러그인은 에이전트에게 디자인 시스템 표준과 미학적 판단(Judgment)을 가르친다.

## 상세

### 6개 지식 레이어 구성
1. **Foundations**: 기초 토큰, 스타일 제약 (타이포그래피 스케일, 테두리 둥글기 등)
2. **Spatial rhythm**: 간격 규칙, 공간 구성 (화면 여백 배치, 내부 간격 토큰 규격)
3. **Composition recipes**: 컴포넌트 조립법, 기본 구성 방식 (테두리 두께 및 정렬 방향 등)
4. **Implementation**: 실제 구현 가이드 (React 등 프론트엔드 프레임워크 코드 템플릿)
5. **Quality and taste**: 브랜드 본연의 감각, 금지 규정 (사용이 금지된 스타일 패턴)
6. **MCP definitions**: 실시간 API 컴포넌트 명세 호출

### 작업 상황별 로딩 흐름
AI 클라이언트(예: Anthropic Claude Code, Cursor)는 작업 상황에 따라 다음과 같이 로딩 흐름을 분기하여 토큰 낭비를 차단하고 일관성을 유지한다 [완전히 기계 읽기 가능한 디자인 시스템-ko.md](../raw/%EC%99%84%EC%A0%84%ED%9E%88%20%EA%B8%B0%EA%B3%84%20%EC%9D%BD%EA%B8%B0%20%EA%B0%80%EB%8A%A5%ED%95%9C%20%EB%94%94%EC%9E%90%EC%9D%B8%20%EC%8B%9C%EC%8A%A4%ED%85%9C-ko.md).
- **`.tsx` / `.ts` 파일이 열려 있을 때**: Foundations 항상 주입
- **코드를 검토하거나 구성할 때**: Quality and taste 주입
- **직접 소스 코드를 생성/수정할 때**: Implementation 주입
- **컴포넌트를 조립할 때**: Composition recipes 주입
- **미세한 여백과 간격을 조율할 때**: Spatial rhythm 주입
- **개별 컴포넌트 규격에 대한 명확한 질문 시**: 실시간 디자인 시스템 MCP 호출

### 이식성 및 패키징
구체적인 분류 체계(Taxonomy)가 클라이언트마다 다를 수 있으므로, 공통으로 겹치는 영역을 이용한다.
- **Anthropic 플러그인 규칙**: `skills/<skill>/SKILL.md`, `agents/*.md`, `references/` 구조 준수
- **Cursor 설정**: `.cursor-plugin/plugin.json` 구성
- 하나의 플러그인을 양쪽 플랫폼 모두에서 로드할 수 있도록 호환 리포지토리를 설계하여 사내 AI 마켓플레이스 유통 및 확장을 보장한다.

## 예시

### Indeed의 Sourcegraph MCP 감사 사례
실제 제품 환경 분석을 위해 디자인 시스템 팀이 14개 제품 코드베이스를 대상으로 Sourcegraph MCP 감사를 실행함. 총 1,697개 파일과 6,147건의 간격 토큰 사용 사례를 분석하여, 디자이너의 주관적 추측을 걷어내고 **6개 핵심 간격 토큰**과 **4개 글로벌 레시피**를 도출하여 Foundations의 뼈대로 삽입함 [완전히 기계 읽기 가능한 디자인 시스템-ko.md](../raw/%EC%99%84%EC%A0%84%ED%9E%88%20%EA%B8%B0%EA%B3%84%20%EC%9D%BD%EA%B8%B0%20%EA%B0%80%EB%8A%A5%ED%95%9C%20%EB%94%94%EC%9E%90%EC%9D%B8%20%EC%8B%9C%EC%8A%A4%ED%85%9C-ko.md).

### 캘리브레이션 테스트를 통한 디자인 튜닝
플러그인 구동 시 가상 화면에서 활성화된 카드(Active cards)의 왼쪽 테두리 강조선(Left-border accent)이 계속 들어가는 현상 발견. 원인 파악 결과, 디자인 시스템상으로는 이미 수년 전 폐기되었으나 공식 가이드라인 문서에 찌꺼기로 남아있던 정책이었음. LLM은 이를 문자 그대로 신뢰하여 렌더링한 것이었음. 즉시 원본 문서를 수정하고 플러그인의 `quality.md`에 명확한 금지 규정을 적용하여 다음 생성에서 문제를 해결함 [완전히 기계 읽기 가능한 디자인 시스템-ko.md](../raw/%EC%99%84%EC%A0%84%ED%9E%88%20%EA%B8%B0%EA%B3%84%20%EC%9D%BD%EA%B8%B0%20%EA%B0%80%EB%8A%A5%ED%95%9C%20%EB%94%94%EC%9E%90%EC%9D%B8%20%EC%8B%9C%EC%8A%A4%ED%85%9C-ko.md).
