# 에이전틱 자동화 루프 패턴

## 한 줄 정의
사용자가 에이전트와 직접 프롬프트를 주고받으며 대화하는 단계를 넘어, 백그라운드 상에서 에이전트를 가두고 테스트 및 빌드를 자율적으로 반복하게 만드는 고성능 에이전트 조율 워크플로우다.

## 핵심 요지
- **추상화 수준의 이동**: 엔지니어는 더 이상 Claude나 Codex에 직접 프롬프트를 입력하지 않고, 백그라운드에서 동작할 조율 루프(Controller Loop) 프로그램을 작성하는 개발 패러다임으로 전환한다.
- **주요 엔지니어들의 사례**:
  - *Boris Cherny (Claude Code)*: 프롬프트 전달과 실행 검증을 하나의 스크립트 루프로 격리하여 자율 수행하도록 코드를 전환함.
  - *Peter Steinberger*: 에이전트를 직접 건드리기보다, 피드백 관점에서 제어 루프를 세분화하여 설계함.
  - *Steve Yegge*: 다중 에이전트 오케스트레이터를 루프 구조 위로 조립함.

## 상세
### 루프 구현 시 고려해야 할 설계 패턴
1. **Context/Prompt 인젝션**: 루프 내부에서 매 반복 주기마다 에이전트에게 이전 턴의 오류 코드, diff 현황을 가공하여 프롬프트로 안전하게 전달해야 한다.
2. **에이전트 이탈 방지**: 시스템 프롬프트를 초과하는 컨텍스트 입력으로 인해 에이전트가 우회로를 찾거나 린터를 임의로 우회하는 행동을 감시한다 (예: 테스트 주석 처리 감지).
3. **비용 효율성 설계**: 자율 루프가 무한 루프에 빠져 API 크레딧을 소진하기 전에 강제로 종료시키는 세션 중단(Halt) 조건을 설계해야 한다.
