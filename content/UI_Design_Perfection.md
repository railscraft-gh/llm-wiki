## 한 줄 정의
제품의 인지 품질(Perceived Quality)을 결정짓는 미세한 UI 디테일 8가지로, 사용자 경험을 세련되게 다듬고 완성도를 높이는 실무 디자인 가이드입니다.

## 핵심 요지
1. **시각적 위계:** 모든 요소에 동일한 강조를 하지 말고, 위계에 따라 무게감을 조정하여 불필요한 강조를 덜어낼 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L25](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L25).
2. **여백 확보:** 여백은 '과하다' 싶을 정도로 넓혀야 가독성과 고급스러움이 살아남 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L53](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L53).
3. **일관된 둥글기:** 테두리 둥글기(Border Radius) 규칙을 정의하여 파편화된 UI 요소를 통일할 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L76](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L76).
4. **완벽한 정렬:** 1~2픽셀의 어긋남이 조잡함을 만들므로 시각적 보정(Optical Balance)과 기준선 정렬에 집착할 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L102](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L102).
5. **색상 절제:** 무채색 바탕에 단 하나의 강조색만 사용하여 명확성과 고급스러움을 완성할 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L139](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L139).
6. **은은한 애니메이션:** 기교가 아닌 마찰을 줄이는 의도적이고 매끄러운 움직임을 설계할 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L166](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L166).
7. **미세 지연(Delay):** 즉각적인 피드백보다 적절한 지연을 통해 리듬감을 부여하여 완성도를 높일 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L195](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L195).
8. **덜어내기:** 더하기보다 불필요한 요소를 용기 있게 삭제하여 자신감 있는 디자인을 구현할 것 [raw/8 Tiny UI Fixes Most Designers Ignore.md#L226](file:///Users/railscraft/Obsidian/raw/8%20Tiny%20UI%20Fixes%20Most%20Designers%20Ignore.md#L226).

## 상세
사용자는 제품의 완성도를 직관적으로 감지합니다. 이 디테일은 거창한 리디자인이나 화려한 효과가 아니라, 집요하고 강박적인 사소한 결정에서 나옵니다. 세련됨은 추가하는 것이 아니라 덜어내고 다듬는 과정에서 완성됩니다.
