# 주의력 배터리

## 한 줄 정의
'주의력 배터리'는 사람이 집중력, 의지력, 자제력을 발휘하기 위해 사용하는 유한하고 소모성인 정신적 에너지 자원을 비유적으로 이르는 개념이다. (raw/How to use your mornings like the most productive 1%.md)

## 핵심 요지
- **유한한 자원**: 아침에 일어났을 때 최고조에 달하며, 하루 동안 크고 작은 의사결정을 내리고 자제력을 발휘할 때마다 점차 소모된다. (raw/How to use your mornings like the most productive 1%.md)
- **최고 효율 스케줄링**: 주의력 배터리가 가장 가득 차 있고 방해 요소가 없는 새벽 및 아침 식사 전 시간대에 집중력이 필요한 핵심 과업을 우선 처리해야 한다. (raw/How to use your mornings like the most productive 1%.md)
- **자아 고갈 유발**: 배터리가 바닥난 상태에서는 유혹에 저항하거나 인지적 연산을 수행할 수 없는 [[자아 고갈 이론|자아 고갈]] 상태에 빠지게 된다. (raw/How to use your mornings like the most productive 1%.md)
- **에이전트 인덱싱 유추**: [[LLM]] 에이전트 시스템에서 토큰 수 누적으로 인해 모델의 명령 준수 능력이 떨어지는 컨텍스트 오염 및 성능 저하 현상을 제어하기 위한 설계 모델로도 차용된다.

## 상세
- **인지 에너지의 생태계**: 인간은 아침에 가장 맑은 에너지와 정신적 자원을 가지며, 이 에너지의 질은 시간에 따라 기하급수적으로 저하된다. (raw/How to use your mornings like the most productive 1%.md) 하루 중 늦은 시간일수록 의지력이 바닥나기 때문에 다이어트 실패, 충동적 구매, 치명적인 오판 등은 대개 늦은 저녁이나 밤에 발생한다. (raw/How to use your mornings like the most productive 1%.md) 
- **의지력의 과학적 입증**: 로이 바우마이스터의 유명한 단식 참가자 실험에 따르면, 초콜릿 쿠키의 유혹을 참는 데 주의력 배터리를 먼저 소모한 빨간 무 섭취군은 난해한 수학 문제를 만났을 때 평균 **8분** 만에 포기했다. 반면, 주의력을 보존한 쿠키 섭취군은 평균 **20분** 동안 포기하지 않고 끈기 있게 매달렸다. (raw/How to use your mornings like the most productive 1%.md)
- **AI 에이전트의 주의력 배터리 현상**: [[LLM]] 기반 에이전트([[인공지능 에이전트]])는 지속해서 도구를 사용하고 긴 대화를 이어가면 컨텍스트 윈도우에 노이즈가 누적되어 지시 사항 준수(Instruction Following)율이 심각하게 떨어진다. 이는 인간이 피로를 느끼고 주의력 배터리가 방전되는 현상과 완벽하게 매칭된다. 시스템 안정성을 위해서는 일정 수준 이상 토큰을 소모했을 때 시스템을 클린(Clean)하게 되돌리는 컴팩션(Compaction)이나, 외부 데이터베이스로 장기 기억을 빼내는 아키텍처가 필수적이다.

## 예시
아래 코드는 에이전트의 주의력 배터리 잔량을 지속적으로 체크하고, 배터리가 임계값 이하로 저하되었을 때 컨텍스트 윈도우를 다시 비우고 요약(Compaction) 처리를 수행함으로써 에이전트의 명령 이행률을 복원하는 파이썬 시뮬레이션 모듈이다.

```python
import time

class AttentionBatteryAgent:
    def __init__(self, name: str, threshold: float = 30.0):
        self.name = name
        self.battery = 100.0  # 초기 주의력 배터리 100%
        self.context_tokens = 0
        self.threshold = threshold
        
    def execute_reasoning(self, task_complexity: float) -> str:
        """에이전트가 복잡한 태스크를 수행할 때 주의력 배터리를 소모합니다."""
        if self.battery <= 0.0:
            return f"❌ [{self.name}] 자아 고갈(Ego Depleted) 상태. 추론을 진행할 수 없습니다."
            
        print(f"\n⚡ [{self.name}] '{self.battery:.1f}%' 배터리 상태에서 추론 시작...")
        
        # 난이도에 따른 배터리 소모 및 컨텍스트 토큰 증가
        cost = task_complexity * 15.0
        self.battery = max(0.0, self.battery - cost)
        self.context_tokens += int(task_complexity * 800)
        
        # 피로도에 따른 성능 경고
        if self.battery < self.threshold:
            print(f"⚠️ [경고] 주의력 배터리가 {self.battery:.1f}%로 떨어졌습니다! 지시사항 유실(Instruction Drifting) 위험이 높습니다.")
            
        return f"✅ [{self.name}] 추론 성공. (컨텍스트 토큰 누적: {self.context_tokens} tokens)"
        
    def perform_compaction(self):
        """주의력 배터리를 회복하기 위한 휴식 및 컨텍스트 정리 작업"""
        print(f"\n🧹 [Compaction 시작] 컨텍스트를 비우고 핵심 사실만 요약 정리하여 주의력 배터리를 복원합니다.")
        time.sleep(0.3)
        self.context_tokens = int(self.context_tokens * 0.15)  # 토큰 대폭 축소
        self.battery = min(100.0, self.battery + 50.0)  # 배터리 50% 회복
        print(f"🌟 [Compaction 완료] 배터리 {self.battery:.1f}%로 충전됨. 잔여 토큰: {self.context_tokens}")

if __name__ == "__main__":
    agent = AttentionBatteryAgent("AGI-Scheduler")
    
    # 작업 연속 수행
    print(agent.execute_reasoning(task_complexity=2.5))
    print(agent.execute_reasoning(task_complexity=3.0))
    
    # 배터리 방전 경고 발생 후, 정리(Compaction) 수행
    if agent.battery < agent.threshold:
        agent.perform_compaction()
        
    print(agent.execute_reasoning(task_complexity=1.5))
```

## 충돌
- **의지력 고갈 논란**: 최근 심리학계 일부에서는 로이 바우마이스터의 자아 고갈 재현 실패 실험 등을 근거로 의지력이 생물학적 한계를 지닌 유한한 배터리라는 가설을 비판하며, 의지력은 고갈되는 자원이 아니라 개개인의 '마음가짐(Mindset)'이나 '보상 체계'에 따라 지속 가능한 심리적 개념이라는 주장(Carol Dweck 등)을 제기하여 전통적인 배터리 모델과 대립한다.
