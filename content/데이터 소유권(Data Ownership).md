# 데이터 소유권(Data Ownership)

## 한 줄 정의
클라우드나 특정 소프트웨어 벤더의 데이터베이스 구독 모델에 종속되지 않고, 평문 마크다운(`.md`) 파일과 로컬 Git 저장소의 형태로 지식 자산을 온전히 사용자가 통제하고 영구 소장하는 권리.

## 핵심 요지
- **벤더 종속 탈피(Lock-in Avoidance)**: 특정 지식 도구의 서비스가 중단되거나 과금 정책이 바뀌더라도 데이터 손실이나 포맷의 왜곡 없이 영원히 지식을 보존할 수 있다.
- **프라이버시 및 오프라인 보장**: 데이터가 전용 데이터베이스나 제3자의 클라우드 서버에 상주하지 않고 로컬 파일 시스템에 있기 때문에 완벽한 정보 보안과 오프라인 접근성이 담보된다.
- **로컬 AI 연동성**: 데이터 구조가 일반적인 평문 형태를 띠므로, 나중에 클라우드 구독형 AI 서비스 대신 로컬 머신에서 구동하는 프라이빗 대형 언어 모델([[로컬 LLM 30분 실전 가이드]])로 손쉽게 전향하여 프라이빗 지식 데이터베이스로 재사용할 수 있다.

## 상세
현대 지식 관리 시스템의 대부분은 사용자의 데이터를 자체적인 포맷이나 클라우드 데이터베이스에 격리시킨다. 이는 초기에는 편리하지만 장기적으로는 벤더 종속을 유발한다. [[COG]] 아키텍처 및 안드레 카파시의 지식 시스템([[Karpathy 지식 시스템]])은 이 문제를 평문 텍스트와 Git, [[옵시디언]]의 조합으로 우회하여 완전한 데이터 소유권을 선언한다.

## 예시
- **[[COG]]의 데이터 소유권 실현 방식**:
  - 모든 콘텐츠 폴더(`00-inbox` ~ `06-templates`)의 노트가 투명한 마크다운 파일로 로컬 디렉터리에 존재함.
  - 시스템 구동용 스크립트와 사용자의 지식 데이터가 완전히 격리되어 업데이트 시에도 사용자 데이터의 무결성이 보장됨.
  - 지식 보존 및 버전 복구를 상용 백업 솔루션 대신 Git 시스템(`git diff`, `git log`)을 활용해 수행함.
