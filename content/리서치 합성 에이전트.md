### 주요 작성 내용 요약

1. **한 줄 정의 및 핵심 요지**:
   - 비구조화된 정성·정량 리서치 자원(녹취록, 설문, 사용성 테스트, 지원 티켓 등)을 [[LLM]]과 자동 코딩·시맨틱 클러스터링 기술로 분석하여, 원본 역추적(Traceability)이 가능한 페르소나, JTBD, 인사이트 문장으로 컴파일하는 에이전틱 워크플로우로 정의.
   - 단순 키워드 매칭을 넘어 사용자의 "Stated Need(말한 요구)"와 "Revealed Need(실제 우회/행동 요구)"의 불일치 감지 기능 기재.
   - 1차 수집·정제 및 클러스터링 오버헤드를 70~90% 절약하고, 디자이너/리서처는 제시된 신뢰도 점수(Confidence score)와 인용구를 검증하는 고차원적 전략 판단에 집중함을 명시.

2. **상세 파이프라인 및 명세**:
   - **5단계 파이프라인**: 1. Ingest & Normalize $\rightarrow$ 2. Code (Open/Axial) $\rightarrow$ 3. Cluster (Semantic Similarity & Confidence Score) $\rightarrow$ 4. Synthesize $\rightarrow$ 5. Cite (Attribution Mapping)
   - **Mermaid 시각화 및 입출력 표**: Plain text, CSV, Dovetail·Notion·Airtable export 수용 및 하류 워크플로우(JSON/CSV) 매핑 체계 구성.
   - **사용 및 제약 경계**: 10건 이상의 인터뷰 축적 시, 다중 라운드 통합 시 등의 적용 상황과 젠더/트라우마/소규모 샘플 등 부적합 상황 제시.

3. **구체적 예시**:
   - **Claude Code CLI용 에이전트 스펙**: `.claude/agents/research-synthesizer.md` 파일에 정의할 수 있는 실제 프롬프트 및 도구 연결 마크다운 예시.
   - **하류 시스템 연동 JSON 스키마**: `jtbd_framework`, `opportunity_areas`, `attributions` 발화 원본 인용 데이터 구조 포함.

4. **충돌 및 학술적 논의**:
   - 전통 UX 리서치 학계의 "비언어적 뉘앙스/직관적 단순화 위험" 우려와 에이전틱 제품 디자인의 "대규모 데이터 인지 과부하 방지 및 1차 오버헤드 절감" 관점 간의 대비를 분석하여 기재.

5. **연동 및 출처**:
