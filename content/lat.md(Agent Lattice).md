# lat.md(Agent Lattice)

## 한 줄 정의

프로젝트 폴더 내 소스 코드와 기술 문서를 유기적으로 파싱·교차 연결하고 참조 무결성을 자동으로 검증하여 AI 에이전트의 작업 생산성을 극대화하는 지식 그래프 구축 도구다.

## 핵심 요지

- **참조 무결성(Referential Integrity) 보장**: 문서에 기재된 개념 및 설계 설명이 실제 밑바닥 소스 코드 구현체와 올바르게 매핑되어 있는지 실시간 추적하고 유실 시 경고한다.
- **선 요약 강제 원칙(Summary-First Rule)**: AI의 무의미한 전체 파일 스캔 및 토큰 낭비를 줄이기 위해, 모든 문서 첫머리에 몇 문장 이내의 요약(Summary) 작성을 필수 요건으로 규정한다.
- **에이전트 SDLC 연동**: 시스템 프롬프트(System prompt)에 생성된 지도를 주입하여, AI 모델이 프로젝트를 변경할 때 코드 세부를 탐색하기에 앞서 검증된 지도를 먼저 참조하도록 유도한다.
- **로컬 기반 프라이빗 연산**: 코드를 외부 서버로 발송하지 않고 로컬 환경에서 20개 이상의 프로그래밍 언어를 파싱하여 안전하게 지도를 작성한다.

## 설치/실행

### 1. 패키지 설치 및 초기화
프로젝트 디렉토리 내에서 패키지를 설치하고 설정을 실행한다. 설정은 대화형으로 구동된다.
```bash
# 초기 설정 명령어 실행 (Interactive CLI)
lat init
```
이 단계에서 사용하는 에이전트 도구([[Claude Code]], [[Cursor]] 등)와의 연동 규칙 및 시스템 프롬프트 가이드가 주입된다.

### 2. 코드 및 문서 스캔
```bash
# 코드 분석 및 지식 매핑
lat scan
```
20여 개 언어를 지원하는 로컬 파서가 클래스, 함수 관계를 추출한다.

### 3. 일관성 검사 및 파이프라인 연동
```bash
# 링크 유실 및 요약 유무 검증
lat check
```
검증에 실패한 문서 조각이 존재할 경우 빌드나 커밋(Commit) 단계에서 차단하도록 Git Hook에 배치할 수 있다.

## 핵심 명령

- `lat init`: 대화형 초기 환경 구성 및 에이전트 시스템 프롬프트 가이드 생성.
- `lat scan`: 로컬 소스 코드 분석을 통한 함수/클래스 의존 관계 구조화.
- `lat check`: 참조 링크의 연결성 보장 및 선 요약 준수 정합성 검사.

## 한계

- **코드 파싱 복잡도**: 고도로 추상화되거나 복잡한 일부 소스 코드 구조에서는 파서가 관계망을 완벽히 추출하지 못하고 간혹 파싱 지점이 끊기는 한계가 존재한다.
- **지속적 유지 관리**: 문서 정합성이 자동 차단막 역할을 하지만, 개발자가 코드 변경 시 주석 및 설명서 링크를 수동 갱신하지 않으면 빌드가 수시로 깨질 수 있어 정갈한 협업 관성이 필요하다.
