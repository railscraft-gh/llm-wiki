# 자동 조종 모드

## 한 줄 정의
뚜렷한 의식적 목적이나 주체적 의지 없이 외부 자극, 습관성 패턴 또는 기계적 관성에 의해 행동이나 처리가 연속적으로 실행되는 수동적 인지 상태.

## 핵심 요지
- **기계적 관성**: 일상적인 습관이나 단순 자극-반응 루프에 의존하여 자각 없이 일정을 흘려보내는 상태.
- **뇌의 에너지 보존**: 인지 자원(Attention Battery)을 아끼기 위한 생존 기전이지만, 주체적인 의사결정과 깊은 몰입을 저해하는 요인이 된다.
- **에이전틱 타성**: LLM 에이전트가 적절한 피드백 루프나 평가 조건(Critic) 없이 관성적으로 답변을 생성하거나 동일한 오류를 반복하는 상태.

## 상세
### 1. 인간의 인지적 자동 조종
현대인은 스마트폰 알람을 확인하는 등의 외부 어포던스(Affordance)에 자극받아 자동 조종 모드에 들어가기 쉽다. 이는 의지력을 소모하지 않는 장점이 있지만, 결과적으로 중요한 목표보다 지엽적이고 사소한 일에 매달려 시간을 낭비하게 만든다. 이를 탈피하기 위해서는 제약 조건과 인지적 긴장감(Stakes)을 주입해야 한다 (raw/You Don’t Need More Time. You Need Better Constraints..md).

### 2. LLM 에이전트의 관성(Autopilot) 문제
에이전트 시스템에서 "자동 조종 모드"는 에이전트가 이전의 비효율적인 행동 양식을 그대로 복사하거나, 문맥 안의 편향에 매몰되어 단순 응답 생성을 지속하는 현상이다. 이를 해결하기 위해 에이전틱 SDLC나 [[하네스_엔지니어링]] 등에서는 의도적으로 추론 흐름을 끊고 상태를 검증하는 모니터링 레이어를 도입한다.

## 예시
- **행동 패턴**: 아침에 눈을 뜨자마자 이메일이나 SNS 앱을 반복적으로 새로고침하는 등의 무의식적 루틴.
- **에이전트 패턴**: 에이전트가 코딩 작업 중 컴파일 에러를 해결하지 못하고 동일한 오류 수정 코드를 반복해서 시도하며 API 토큰을 낭비하는 무한 루프 상태.
