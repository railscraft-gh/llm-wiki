# 디자인 에이전트 5종

## 한 줄 정의

디자인 에이전트 5종은 리서치 정리부터 문제 정의, 아이디어 발산, 경쟁 정보 추적, UX flow 설계까지 제품 디자인의 사고 비용이 큰 단계를 agent workflow로 분해한 패턴 모음이다.

## 핵심 요지

- 강한 디자인 agent는 intent alignment, context awareness, tool orchestration, explainability를 함께 갖춰야 한다.
- 이 프레임은 화면을 바로 그리기보다 research → define → ideate → flow design 순서의 upstream design work를 구조화하는 데 강하다.
- 핵심 가치는 디자이너를 대체하는 것이 아니라, 반복적 분석과 초안 생성을 자동화해 사람이 더 높은 판단에 집중하게 만드는 데 있다.
- 이 노트는 디자인 조직이 어떤 사고 단위를 agent workflow로 잘게 쪼갤 수 있는지 보여 주는 상위 task map으로 재사용 가치가 높다.

## 상세

원문은 Claude Code 안에서 바로 만들 수 있는 다섯 agent를 제안한다. **Research Findings Synthesizer**는 인터뷰, 설문, usability note를 theme, persona, JTBD, insight statement로 구조화한다. **Competitor Intelligence Agent**는 경쟁사 changelog, pricing, 리뷰, 포지셔닝 변화를 지속적으로 추적한다. **Problem Definition Agent**는 해결책처럼 보이는 모호한 요청을 검증 가능한 문제 정의로 다시 쓴다. **Idea Generation Agent**는 solution space를 넓혀 서로 다른 UX 접근과 off-axis concept를 만든다. **UX Flow Designer Agent**는 선택된 concept를 happy path, edge case, friction audit가 포함된 구조화된 flow로 바꾼다.

이 패턴은 [[DESIGN.md 운영 원칙]]과 역할이 다르다. DESIGN.md가 visual consistency를 위한 지속 문맥이라면, 디자인 에이전트 5종은 제품 디자인 workflow의 각 단계를 수행하는 task agent 묶음이다. 다시 말해 하나는 **디자인 언어를 고정하는 파일**이고, 다른 하나는 **그 언어 위에서 어떤 디자인 사고를 자동화할지 정하는 절차**다. [[AI 디자인 역할 맵]]에서는 이 노트를 세 번째 task layer로 본다.

또한 이 흐름은 [[AI 산출물 포맷 결정 트리]]와도 연결된다. research synthesis나 competitor digest는 사람이 읽는 HTML artifact가 유리할 수 있고, problem brief나 flow spec은 git 추적과 후속 agent 입력을 위해 Markdown source가 더 적합할 수 있다. 어떤 agent든 claim traceability와 설명 가능성을 남기는 것이 중요하다.

## 적용 체크리스트

- 지금 자동화하려는 일이 시각 polish가 아니라 research·define·ideate·flow 같은 upstream 작업인가.
- 산출물이 화면보다 brief, insight, spec, flow에 가까운가.
- claim traceability와 human review 지점을 남길 수 있는가.
- [[DESIGN.md 운영 원칙]] 같은 시각 기본값 파일과 역할이 섞이지 않는가.

## 예시

- discovery 이후 인터뷰 12건이 쌓였을 때: Research Findings Synthesizer로 theme와 JTBD 초안 생성
- roadmap 정의 전: Problem Definition Agent로 “이탈률이 높다”를 검증 가능한 문제 정의로 압축
- solution workshop 전: Idea Generation Agent로 5~10개 concept set 생성
- 복잡한 onboarding 개편 전: UX Flow Designer Agent로 happy path, edge case, friction map 작성

현재 확인된 충돌 없음.
