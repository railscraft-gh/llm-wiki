### 3. 예시 시뮬레이션 코드 검증
실제 구동을 테스트하기 위해 `test_smc.py`를 임시 생성하여 수행한 결과입니다:
```bash
$ python3 test_smc.py
--- 시각 서보 제어 루프 시작 (타겟 실제 위치: 15.0°) ---
[Step 1] 감각 입력 (상대 오차): +15.00°
[Actuator] 회전 운동 적용: +9.00° | 현재 고개 각도: 9.00°
[Step 2] 감각 입력 (상대 오차): +6.20°
[Actuator] 회전 운동 적용: +3.72° | 현재 고개 각도: 12.72°
[Step 3] 감각 입력 (상대 오차): +2.54°
[Actuator] 회전 운동 적용: +1.52° | 현재 고개 각도: 14.24°
[Step 4] 감각 입력 (상대 오차): +0.26°
[Sensorimotor Control] 타겟이 시야의 정중앙에 위치함. 행동 유지.
```
* **결과**: 절대 좌표에 대한 이해 없이도, 감각-운동 수반성을 통해 에이전트가 안정적으로 타겟 추적 행동을 조율해 나가는 것을 확인했습니다.
