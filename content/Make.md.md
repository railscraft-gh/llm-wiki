# Make.md

## 한 줄 정의
**Make.md**는 옵시디언(Obsidian)의 마크다운 보관소(Vault)를 주제별 '스페이스(Space)'와 모듈형 '카드(Card)' 단위의 시각적 UI/UX 작업 공간(Workspace)으로 전환하여 지식 관리의 탐색 마찰을 최소화하는 옵시디언 플러그인 도구입니다.

## 핵심 요지
- **파일 묶음에서 유기적 작업 공간으로의 전환**: 단순 텍스트 폴더 및 파일 트리 구조에 머물던 옵시디언 보관소를 시각적이고 모듈화된 지식 작업 공간으로 재구성합니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).
- **시각적 내비게이션 기반 스페이스(Space)**: "대학원 연구", "읽어야 할 논문", "초안 작성"과 같은 주제별 스페이스 환경을 구성하여 "노트가 어디 있는지 기억해 낼 필요" 자체를 없애줍니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).
- **모듈형 카드(Card) 시스템**: 텍스트 목록 대신 모듈형 카드 단위를 도입하여 노션(Notion) 수준의 직관적이고 경량화된 visual UI 경험을 선사합니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).
- **100% 로컬 마크다운 파일 유지**: 노션과 같은 가볍고 세련된 인터페이스를 구현하면서도 데이터 록인(Lock-in) 없이 로컬 마크다운(Local Markdown) 파일 고유의 이점과 소유권을 완벽히 지켜냅니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).

## 상세

### 1. 배경 및 문제 의식
전통적인 옵시디언 보관소(Vault)는 파편화된 노트, 복잡하게 얽힌 폴더 트리, 일관성 없는 메타데이터로 인해 필요한 노트를 찾는 데 높은 인지적 마찰(Friction)이 발생합니다. Make.md는 이러한 '정보 창고' 상태의 보관소를 '유기적 지식 시스템'으로 변환하기 위해 등장했습니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).

### 2. 핵심 아키텍처 및 주요 기능

| 핵심 기능 | 설명 및 이점 |
| :--- | :--- |
| **스페이스 (Space)** | 프로젝트, 연구 영역, 작업 목적에 맞춘 주제별 시각적 샌드박스/작업 환경 구성 |
| **카드 (Card)** | 노트를 단편적 텍스트 줄이 아닌 직관적 모듈 단위로 시각화하여 정보 가독성 향상 |
| **시각적 내비게이션** | 텍스트 폴더 깊이를 무한 탐색하는 대신, 스페이스 이동만으로 관련 노트들에 즉시 접근 |
| **로컬 지속성** | 데이터베이스 서버 연동 없이 100% 로컬 마크다운 파일 구조와 완벽 호환 |

### 3. [[옵시디언 마찰 최소화 워크플로우]] 내에서의 시너지
Make.md는 대형 보관소 구축 시 발생하는 탐색 병목을 직접 해결합니다.
- **QuickAdd**로 캡처된 신규 노트가 메타데이터 기반으로 정돈되면, Make.md의 관련 **스페이스** 뷰에 즉시 시각적으로 노출됩니다.
- **Linter**로 정제된 깔끔한 마크다운 메타데이터 및 카드가 Make.md 카드 뷰에 일관되게 표시되어 서식 유지를 위한 사용자 개입을 최소화합니다.
- **Omnisearch** 및 **Calendar**와 조합되어 수집-정리-탐색-추적으로 이어지는 마찰 제로 지식 시스템을 형성합니다.

## 예시

### 대학원 연구 워크플로우에서의 Make.md 스페이스 활용 시나리오
대학원생 연구자가 Make.md를 활용해 3대 주력 스페이스를 구성하고 연구 마찰을 줄이는 구체적 구조 예시입니다 (raw/5개의 새로운 플러그인으로 옵시디언 워크플로우 재구축하기 (2026년 설정).md).

#### 1. 스페이스 구성 (Space Configuration)
- **`[Space] 대학원 연구`**: 현재 진행 중인 논문 주제 관련 모듈 카드 모음.
- **`[Space] 읽어야 할 논문`**: QuickAdd로 수집된 읽기 대기 상태(`status: reading`)의 논문 요약 카드.
- **`[Space] 초안 작성`**: 실제 집필 중인 논문 단단 및 섹션 노트들의 모듈화 배치.

#### 2. 카드 뷰에 연동되는 노출 마크다운 예시
```markdown
---
type: research_paper
status: reading
space: "읽어야 할 논문"
tags:
  - paper
  - traffic_model
author: "[[John Doe]]"
title: "Traffic Model Calibration Methods"
created: 2026-08-27
updated: 2026-08-27
---

# Traffic Model Calibration Methods

## 스페이스 카드 요약
- **연구 영역**: 교통 모델 보정 및 시뮬레이션
- **핵심 질문**: 딥러닝 기반 파라미터 최적화 프레임워크 타당성 검증
- **관련 스페이스**: [[Make.md]] 스페이스 "대학원 연구" 및 "초안 작성"과 연동
```

연구자는 복잡한 폴더 경로(`Vault/Research/2026/Papers/...`)를 기억할 필요 없이, Make.md의 `"읽어야 할 논문"` 스페이스를 열고 시각적 카드 뷰에서 해당 노트를 바로 선택하여 작업할 수 있습니다.
