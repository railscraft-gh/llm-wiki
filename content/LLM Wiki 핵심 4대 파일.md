---# LLM Wiki 핵심 4대 파일

## 한 줄 정의

인간뿐만 아니라 LLM 에이전트가 지식을 정확하게 추출하고 협업할 수 있도록 뼈대 역할을 하는 4대 구성 파일(Index, Log, Rule, Schema)의 집합.

## 핵심 요지
- Index(지도): 위키에 진입한 AI 에이전트가 대분류, 중분류 및 핵심 문서로 최단 거리에 도달하도록 안내하는 전체 지도로서, 전수조사로 인한 연산 비용과 시간 낭비를 원천 방지한다.
- Log(역사): 에이전트 명령 이력, 의사결정 변경 사유, 프로젝트 상태 변화 등을 시계열로 기록하여 과거 맥락을 파악하고 엉뚱한 결과 도출을 예방한다.
- Rule(헌법): AI 에이전트의 톤앤매너, 출처 명시 의무, 예외 프로세스 등 행동 수칙을 규정하는 프롬프트 엔지니어링의 핵심 지침서로 할루시네이션을 줄인다.
- Schema(틀): 속성(프런트매터)과 본문 구조(개요, 사용자 인터랙션 등)의 표준 명세를 규정하여 에이전트가 변수를 정확히 추출하고 정형화된 데이터 분석을 수행하도록 돕는다.

### LLM Wiki 4대 마스터 파일의 상세 역할

1. **Index (전체 지도)**
   - **역할**: LLM Wiki의 대시보드이자 최상위 개념의 허브. 에이전트가 위키에 진입했을 때 가장 먼저 펼쳐보는 시작점이다.
   - **구축 팁**: 단순히 제목만 나열하지 않고, 각 섹션이 어떤 목적을 가진 공간인지 짤막한 설명과 함께 링크(`위키링크`)로 구성한다.

2. **Log (역사책)**
   - **역할**: 지식 베이스 내에서 일어나는 상태 변화와 협업 타임라인의 누적 기록.
   - **구축 팁**: 파일 생성 날짜뿐만 아니라 진행 중인 프로젝트 상태 변화, 명령 프롬프트 이력, 디자인 변경 사유 등을 시계열 순서로 기입해 협업의 연속성을 유지한다.

3. **Rule (행동 헌법)**
   - **역할**: 에이전트가 위키 내부에서 지식을 가공, 편집, 출력할 때 지켜야 할 엄격한 지침서.
   - **구축 팁**: 톤앤매너, 금지 조항, 특정 예외 상황 대처법(예: '개념 생성 시 반드시 출처 링크 기재')을 기재하여 환각(Hallucination) 현상을 방지하고 일관성을 강제한다.

4. **Schema (데이터 명세)**
   - **역할**: 노트의 메타데이터(프런트매터) 필수 항목과 본문 섹션 구조를 규정하는 표준 가이드라인.
   - **구축 팁**: 작성일, 플랫폼, 상태 등의 속성명과 본문 뼈대(개요, 인터랙션, 디자인 시스템 반영 여부 등)를 통일하여 AI가 변수 추출 및 구조적 분석을 매끄럽게 수행할 수 있도록 만든다.

## 예시

## 예시

### 1. Index 파일 구조 예시
```markdown
# LLM Wiki Index

## 핵심 카테고리
- [[Agent Harness]] · 에이전트 안전 실행 하네스
- [[Context Engineering]] · 컨텍스트 설계 및 최적화
- [[LLM Wiki 핵심 4대 파일]] · 위키 뼈대를 이루는 4대 파일 명세
```

### 2. Log 파일 작성 방식 예시
```markdown
# LLM Wiki Log

## 2026-07-10
- [Compile] `raw/옵시디언, LLM Wiki에서 가장 중요한 파일 4가지.md` 처리 완료.
- [Create] [[LLM Wiki 핵심 4대 파일]] 신규 노트 생성.
- [Update] [[LLM Wiki 운영 패턴]] 보강.
```

### 3. Rule 파일 작성 예시
```markdown
# LLM Wiki Rules

- 규칙 1: 모든 개념 노트는 최소 2개 이상의 서로 다른 소스 파일에서 포착되었을 때만 승급한다.
- 규칙 2: 수치나 지표가 들어간 모든 문장에는 문단 내에 출처 링크를 명시한다.
```

### 4. Schema 파일 예시 (프런트매터 규약)
```yaml
---
type: concept | tool | workflow | claim
status: seed | draft | evergreen | needs-review | deprecated
core: true | false
tags: [llm, agent]
sources: [raw/파일명.md]
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```
