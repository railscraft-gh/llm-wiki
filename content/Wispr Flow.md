# Wispr Flow

## 한 줄 정의
macOS의 모든 애플리케이션 환경에서 커서가 위치한 곳에 말하는 대로 구두점까지 말끔하게 실시간 입력해 주는 유료 음성 받아쓰기(Dictation) 소프트웨어.

## 핵심 요지
- **기능적 특성**: 회의록을 녹음하고 정리하는 트랜스크립션(Transcription) 도구가 아닌, 사용자 말소리를 텍스트로 직접 변환해 입력창에 주입하는 음성 인식 받아쓰기(Dictation) 도구.
- **주요 가치**: 키보드 타이핑 대비 월등히 빠른 입력 속도를 제공하여 문서 작성 및 메시지 응답의 인지적 마찰과 물리적 피로도를 크게 줄여줌.
- **구독 비용**: 월 $15/월 (`raw/2026년 나의 전체 생산성 스택. 실제로 사용하는 모든 도구, 지출 비용, 그리고 거부한 도구들.md`).
- **핵심 사용처**: 타이핑 작업량이 많은 지식 근로자의 이메일 초안 작성, Slack 메시지 작성, 개요 작성, Jira 코멘트 및 프로젝트 문서(Brief) 작성.

## 상세
Wispr Flow는 운영체제(macOS) 전역에서 작동하는 음성 받아쓰기 솔루션이다. 사용자가 애플리케이션을 가리지 않고 텍스트 커서를 놓은 뒤 자연스럽게 이야기하면, 구두점을 포함한 정돈된 텍스트로 자동 변환하여 커서 위치에 입력해 준다.

1. **타이핑 피로 완화 및 시간 절약**: 하루 3시간 이상 타이핑을 수행하는 고부하 지식 근로자(예: 대기업 PM 겸 창작자)의 손목 통증을 예방하고 작성 속도를 극대화한다. 타이핑만으로 처리하기 부담스러운 500단어 분량의 이메일 초안도 음성 받아쓰기를 통해 약 2분 만에 완성할 수 있다 (`raw/2026년 나의 전체 생산성 스택. 실제로 사용하는 모든 도구, 지출 비용, 그리고 거부한 도구들.md`).
2. **범용성과 근육 기억 적용**: 특정 에디터나 웹사이트에 귀속되지 않고 Mac 내 모든 앱(Slack, Jira, 마크다운 에디터, 웹 브라우저 등)에서 동일한 단축키와 입력 경험(손가락 근육 기억)으로 작동한다. 코딩을 제외한 전체 문서 작성 과업의 약 40%를 음성 입력으로 처리할 수 있을 정도의 실용성을 가진다 (`raw/2026년 나의 전체 생산성 스택. 실제로 사용하는 모든 도구, 지출 비용, 그리고 거부한 도구들.md`).
3. **기본 기능과의 차별성**: macOS 내장 무료 받아쓰기 기능에 비해 인식 정확도와 자연스러운 구두점 처리 능력에서 극적인 우위를 보인다 (`raw/2026년 나의 전체 생산성 스택. 실제로 사용하는 모든 도구, 지출 비용, 그리고 거부한 도구들.md`).
4. **제약 사항**: 받아쓰기 특성상 주변 소음이 제어되는 합리적으로 조용한 환경이나 사적 공간이 요구되므로, 개방형 사무실 환경이나 하루 타이핑 시간이 1시간 미만인 환경에서는 구독 ROI가 낮을 수 있다 (`raw/2026년 나의 전체 생산성 스택. 실제로 사용하는 모든 도구, 지출 비용, 그리고 거부한 도구들.md`).
