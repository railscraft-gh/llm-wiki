## 한 줄 정의
Claude Code의 기능을 특정 작업(슬라이드 제작, 데이터 정제, 비디오 생성, 프로젝트 관리 등)에 최적화하여 결과물의 품질을 높이는 재사용 가능한 지시사항 모음입니다.

## 핵심 요지
- **도구 효율화:** 순수 텍스트 프롬프팅만으로는 평범한 결과물만 얻을 수 있으나, 스킬을 활용하면 전문적인 프로덕션 수준의 작업이 가능합니다.
- **주요 활용 스킬:**
    - **Frontend Slides:** HTML 기반 프레젠테이션 생성.
    - **XLS:** Excel/CSV 데이터 분석 및 정제.
    - **Figma:** 디자인 생성 및 코드 연동.
    - **Remotion:** 제품 설명 비디오 자동 제작.
    - **Codex:** 토큰 효율적인 코드 리뷰 및 리서치.
    - **PM-Skills:** Atlassian(Jira/Confluence) 도구 연동 프로젝트 관리.
- **가치:** 반복적인 일반 업무를 기계가 신뢰성 있게 처리하도록 가이드라인을 제공하여 인적 오류를 줄입니다.

## 상세
스킬은 별도의 빌드 과정 없이 마크다운과 스크립트만으로 작성된 재사용 가능한 지침서입니다. 특히 디자인 영역(Frontend Design, Figma)과 데이터 영역(XLS), 리서치(Codex) 스킬을 결합하면 Claude Code를 단순한 [[코딩 에이전트]]를 넘어 생산성 플랫폼으로 진화시킬 수 있습니다.
