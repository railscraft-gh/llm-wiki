# 모델 컨텍스트 프로토콜 ([[Model Context Protocol]], MCP)

## 한 줄 정의
모델 컨텍스트 프로토콜([[Model Context Protocol]], MCP)은 AI 모델이 외부 데이터 소스(데이터베이스, 웹 API 등), 파일 시스템, 그리고 다양한 개발 도구들과 안전하고 일관되게 소통할 수 있도록 인터페이스를 규격화하는 개방형 프로토콜 표준이다.

## 핵심 요지
- **통합 표준화**: 에이전트 프레임워크나 모델별로 매번 다른 커스텀 도구 바인딩 코드를 작성할 필요 없이, 단일 프로토콜로 모든 외부 자원을 표준 클라이언트-서버 구조로 연결한다.
- **선언적 도구 마운트**: 에이전트 런타임에 외부 도구(Tools), 읽기 전용 데이터(Resources), 사전에 정의된 대화 템플릿(Prompts)을 JSON-RPC 기반 명세로 자동 감지 및 활성화할 수 있게 돕는다.
- **보안 및 제어 격리**: 외부 실행 환경을 샌드박싱하고 하네스 수준에서 실행 권한을 통제함으로써, 모델이 직접 원격 셸 명령이나 민감한 API를 함부로 호출하는 오작동을 차단한다.

## 상세
모델 컨텍스트 프로토콜(MCP)은 복잡해지는 에이전트 생태계의 도구 및 컨텍스트 파편화를 해소하기 위해 제안된 개방형 통신 프로토콜이다.

### 1. 시스템 아키텍처
MCP는 기본적으로 **Client-Host-Server** 형태의 아키텍처를 따른다.
- **MCP Host**: AI 애플리케이션(예: Claude Desktop, 에이전트 프레임워크 등)으로, LLM 및 사용자 입력을 받아 제어를 통제한다.
- **MCP Client**: Host 내부에서 동작하며, 다수의 로컬/원격 MCP Server들과의 세션을 맺고 메시지를 중계한다.
- **MCP Server**: 실제 외부 데이터베이스 쿼리, 파일 시스템 IO, GitHub API 연동 등 특정 도메인의 비즈니스 로직과 도구 스키마 명세를 보관하고 직접 연산을 수행한다.

### 2. 제공 서비스 3대 축
1. **Resources (리소스)**: 모델이 읽을 수 있는 파일, 데이터베이스 레코드 등의 정적/동적 데이터 소스를 URI 형식으로 표준 바인딩해준다.
2. **Prompts (프롬프트)**: 에이전트가 흔히 수행하는 작업에 대한 시스템 프롬프트 및 컨텍스트 템플릿을 정형화하여 제공한다.
3. **Tools (도구)**: LLM이 추론 과정에서 호출(Function Calling)할 수 있는 실행형 함수 명세를 제공하고, 호출 결과를 다시 모델 컨텍스트로 라우팅한다.

## 예시
- **프로젝트 린터 연결**: 에이전트가 로컬 디렉터리 린팅 및 검증 도구를 호출하기 위해 커스텀 파이썬 파서를 작성할 필요 없이, 해당 언어 전용 MCP 린터 서버를 마운트하여 표준적인 JSON-RPC 통신을 통해 에러 피드백을 전달받아 작업하는 아키텍처.

## 충돌
- **네트워크 레이턴시 및 벤더 락인**: 다중 원격 MCP 서버와 통신할 때 네트워크 대기 시간이 누적되어 실시간 에이전트 반응성이 저하될 수 있다. 또한 프로토콜 표준이 특정 기업에 의해 주도되는 경우 다른 런타임 프레임워크와의 하위 호환성 유지에 관한 갈등이 존재할 수 있다.
