### 📝 작성된 위키 내용 요약

* **한 줄 정의**: 최신 Gemini 모델 기반의 강력한 디자인 분석 및 코드 변환 기능을 탑재한 AI-first 개발 플랫폼이자 소프트웨어 개발 도구입니다.
* **핵심 요지**:
  * **디자인의 코드 변환**: 디자인 도구(Moonchild AI 등)에서 기획 및 설계한 UI 구조를 높은 싱크로율로 프론트엔드 코드로 구현합니다.
  * **다양한 인터페이스 제공**: Antigravity CLI(`agy`), Antigravity IDE, Antigravity 2.0, 그리고 Python SDK(`google-antigravity`)를 모두 지원합니다.
  * **디자인과 개발의 괴리 최소화**: 개발 프로세스 3단계(ChatGPT 기획 ➔ Moonchild AI 설계 ➔ Antigravity 개발)를 통해 MVP 개발 기간을 10분의 1 수준으로 단축합니다.
* **상세 내용 및 예시**:
  * Antigravity Python SDK(`google-antigravity`)를 활용하여 프로그램 방식으로 에이전트를 제어하고, 실시간 토큰 및 추론 과정을 스트리밍하는 비동기 코드 예시를 수록하였습니다.
  * 터미널 환경에서 인터랙티브하게 AI 에이전트와 상호작용하는 Antigravity CLI(`agy`) 시나리오를 포함시켰습니다.
