### 💡 주요 작성 및 보강 내용 요약

1. **개념 규정 및 핵심 요지**:
   - 1차 벡터 검색 결과에 대한 에이전트 기반 평가기(Evaluator/Grader Gate) 도입 및 조건부 분기(Correct / Ambiguous / Incorrect) 알고리즘 명시.
   - 검색 문서의 신뢰도가 떨어지거나 모호할 때 외부 웹 서치 API(Tavily, DuckDuckGo 등)를 동적으로 가동하여 신선하고 깨끗한 지식 조각을 수혈·교정하는 메커니즘 기재.
   - LangGraph와 같은 상태 기반 동적 그래프 제어 시스템(Agentic Frameworks)과의 연결성 정립.
2. **구체적 실무 예시 및 아키텍처**:
   - CRAG 흐름을 한눈에 파악할 수 있는 `Mermaid` 시퀀스 플로우차트 수록.
   - LangGraph와 LangChain Framework를 기반으로 문서 관련성 채점(`GradeDocuments`), 쿼리 재작성(`transform_query`), 웹 서치 우회(`web_search`), 조건부 분기(`decide_to_generate`)를 처리하는 실행 가능한 파이프라인 Python 코드 제공.
   - 실시간 뉴스/금융 시장 동향 리포트 및 의료/제약 임상 지침 가드레일 활용 시나리오 수록.
3. **충돌 섹션 (Conflict Resolution)**:
   - **외부 웹 서치 수혈 관점** vs **내부 격리망에서의 기권(Abstain) 처리 관점** 간의 전략적 설계 충돌 정리.
   - 문장 단위 성찰 토큰 기반 **Self-RAG**와 외부 지식 수혈 중심의 **CRAG** 간 연관성과 차이점 비교 분석.
