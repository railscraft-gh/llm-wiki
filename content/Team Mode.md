# Team Mode

## 한 줄 정의
에이전트 오케스트레이터 프레임워크에서 병렬 멀티 에이전트 협업을 가능케 하는 옵트인 모드.

## 핵심 요지
- **멀티 에이전트 오케스트레이션**: 최대 8명의 멤버(동시 4명 실행)가 메일박스와 P2P 메시징으로 분업.
- **주요 도구**: 12개 `team_*` API 도구를 제공하여 리드-멤버 협상 및 종료 제어.
