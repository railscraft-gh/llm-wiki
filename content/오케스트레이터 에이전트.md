### 💡 작성 주요 내용 요약

1. **한 줄 정의**: 복잡한 목표를 원자적 서브태스크로 해체하고 전문 에이전트(Specialist Agent) 및 이종 외부 시스템(MCP, Sentry, GitHub 등)에 적절히 할당·조율하여 최종 결과물을 합성하는 중앙 지휘형 LLM 에이전트 아키텍처 패턴.
2. **핵심 요지**:
   - 업무 자동화 사령탑 역할 (Slack, GitHub, Sentry, Notion, n8n 연동)
   - "전문화된 소수가 일반주의자보다 강하다"는 원칙 기반 서브 에이전트 조율
   - 선 계획 후 실행 (Plan-First Execution) 모드 적용
   - 오버헤드 방지를 위한 서브 에이전트 과다 생성 경고 및 최소화 가이드
3. **상세 및 다이어그램**: Mermaid 구조도 기반의 동작 메커니즘 수립 및 단일 에이전트 vs 오케스트레이터 아키텍처 비교표 수록.
4. **구체적 코드 예시 & 실무 시나리오**:
   - Python 기반 Sentry 에러 감지 $\rightarrow$ Plan 수립 $\rightarrow$ 검증 루프 실행 오케스트레이터 코드 예시
   - Claude Code / CLI 기반 5개 대화 세션 병렬 조율 시나리오
5. **충돌 섹션**: 단일 에이전트의 단순성 유지 관점(Boris의 서브 에이전트 과다 설계 경고) vs 다중 에이전트 전문화 필수론 간의 대립 및 절충안 서술.
