# 평문 텍스트 지속성

## 한 줄 정의
데이터를 특정 기업의 클라우드나 독점 데이터베이스 포맷이 아닌 로컬 표준 마크다운(`.md`) 또는 텍스트 형태로 보관하여 수십 년이 지나도 소프트웨어 종속 없이 읽고 수정할 수 있도록 보장하는 원칙.

## 핵심 요지
- **벤더 종속성(Vendor Lock-in) 해지**: 노션, 에버노트, 롬리서치 등 3사 서비스의 중단, 인수, 요금 인상 또는 내보내기 규격 변경 리스크로부터 개인 데이터 보호.
- **수십 년 수명주기 보장**: 옵시디언이 당장 서비스를 종료하더라도 OS 기본 텍스트 편집기(VS Code, vim, emacs 등)를 통해 [100% 온전히 데이터를 유지하고 개방](file:///Users/railscraft/Obsidian/raw/%EC%98%B5%EC%8B%9C%EB%94%94%EC%96%B8%20%EB%A7%88%EC%8A%A4%ED%84%B0%ED%95%98%EA%B8%B0%20-%20%EB%85%B8%ED%8A%B8%EB%A5%BC%20%EC%84%B8%EC%BB%A8%EB%93%9C%20%EB%B8%8C%EB%A0%88%EC%9D%B8%EC%9C%BC%EB%A1%9C%20%EB%A7%8C%EB%93%9C%EB%8A%94%20%EC%99%84%EB%B2%BD%20%EA%B0%80%EC%9D%B4%EB%93%9C.md#L119-L130).
- **고속 성능 실현**: 독점 렌더링 블록 없이 무거운 DB 조회 오버헤드를 배제하므로 [5만 단어 메모 조회를 100ms 미만으로 즉시 처리](file:///Users/railscraft/Obsidian/raw/%EC%98%B5%EC%8B%9C%EB%94%94%EC%96%B8%20%EB%A7%88%EC%8A%A4%ED%84%B0%ED%95%98%EA%B8%B0%20-%20%EB%85%B8%ED%8A%B8%EB%A5%BC%20%EC%84%B8%EC%BB%A8%EB%93%9C%20%EB%B8%8C%EB%A0%88%EC%9D%B8%EC%9C%BC%EB%A1%9C%20%EB%A7%8C%EB%93%9C%EB%8A%94%20%EC%99%84%EB%B2%BD%20%EA%B0%80%EC%9D%B4%EB%93%9C.md#L38).

## 상세
- **독점 클라우드 vs 평문 텍스트 수명주기**:
  - 클라우드 SaaS: 서버 종료 시 접속 불가 / 데이터 이전 마찰 극심
  - Local Plain-Text: 계정 비필수, 암호화 저장(AES-256), 기기 변경 및 오프라인 전면 지원

## 예시
- 옵시디언 18명 소규모 개발팀이 벤처 캐피탈 자금 없이 [월간 활성 사용자 150만 명(2026년 2월 기준)](file:///Users/railscraft/Obsidian/raw/%EC%98%B5%EC%8B%9C%EB%94%94%EC%96%B8%20%EB%A7%88%EC%8A%A4%ED%84%B0%ED%95%98%EA%B8%B0%20-%20%EB%85%B8%ED%8A%B8%EB%A5%BC%20%EC%84%B8%EC%BB%A8%EB%93%9C%20%EB%B8%8C%EB%A0%88%EC%9D%B8%EC%9C%BC%EB%A1%9C%20%EB%A7%8C%EB%93%9C%EB%8A%94%20%EC%99%84%EB%B2%BD%20%EA%B0%80%EC%9D%B4%EB%93%9C.md#L8)을 기록하는 생태계를 평문 지식 보관 원칙으로 구축.
