## 한 줄 정의
Linear, Notion, Stripe 등 선두 SaaS 제품들이 사용하는, 사용자 인지 부하를 줄이고 전환율을 높이는 12가지 검증된 UI/UX 설계 패턴입니다.

## 핵심 요지
- **점진적 온보딩:** 복잡한 기능 대신 핵심 가치를 우선 경험하도록 정보 전달을 순차적으로 분할.
- **의도적 빈 화면:** 단순히 안내 문구만 띄우지 않고, CTA를 포함하여 첫 행동을 유도하는 '전환의 순간'으로 활용.
- **인라인 유효성 검사:** 제출 후 에러를 찾는 대신 실시간 입력을 검증하여 마찰 최소화.
- **커맨드 팔레트(⌘K):** 메뉴 탐색 단계를 대폭 줄여 키보드 중심의 숙련자 친화적 탐색 제공.
- **스켈레톤 스크린:** 로딩 스피너 대신 구조적 정보를 먼저 제공하여 심리적 대기 시간 개선.

## 상세
최고의 SaaS 제품들은 유저가 이탈하기 쉬운 마찰 지점을 정교하게 설계된 UI 패턴으로 해결합니다. 인라인 검증으로 에러를 즉시 수정하게 하고, 스켈레톤 스크린으로 대기 시간을 심리적으로 짧게 만들며, 맥락 기반 도움말(툴팁)로 흐름을 끊지 않고 의문을 해결합니다. 이는 화려한 비주얼보다 사용자의 인지적 여정을 매끄럽게 다듬는 설계의 미학입니다.
