# RAG 퓨전 (RAG-Fusion)

## 한 줄 정의
사용자의 단일 질문을 LLM을 거쳐 다각도의 다중 쿼리(Multi-Query)로 확장 생성한 뒤, 각 쿼리로 검색된 문서 군을 역순위 융합(Reciprocal Rank Fusion, RRF) 알고리즘으로 재정렬하여 최종 검색 품질을 최적화하는 RAG 검색 기법.

## 핵심 요지
- **어휘 불일치 극복**: 단일 질문에 의존하는 기존 RAG의 검색 한계를 보완하기 위해 동의어나 다른 관점을 반영한 변형 질문군을 활용함으로써 그물망을 촘촘히 쳐서 정보를 누락 없이 수집한다.
- **역순위 융합(RRF) 적용**: 여러 병렬 검색 테이블에서 반복해서 상위권에 도출된 신뢰할 만한 문서의 우선순위를 기하급수적으로 끌어올리고 관련도가 낮은 노이즈 문서는 뒤로 밀어낸다.
- **적은 리소스 고효율**: 별도의 기계학습 기반 크로스 인코더 리랭커(Cross-Encoder Reranker)를 구동하는 것에 비해 수학적 순위 융합만으로 구현이 단순하고 결정적이며 연산 자원 소모가 적다.

## 상세
- **다중 쿼리 생성**: 사용자의 입력 쿼리(예: "What is task decomposition for LLM agents?")를 받으면 LLM을 사용하여 문장 구조나 유의어(예: "break down complex tasks", "methods for decomposing tasks")를 조정한 4~5개의 대안 질문을 자동으로 재생산한다.
- **RRF(Reciprocal Rank Fusion) 알고리즘**:
  - 다중 쿼리 결과로 쏟아진 다량의 문서 정렬 리스트들을 하나로 정합한다.
  - 임의의 문서 $d$에 대한 융합 점수(RRF Score)는 각 쿼리 $m \in M$의 결과 목록에서의 순위 $r_m(d)$에 대해 다음 공식을 따른다.
    $$Score(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$
    (여기서 $k$는 랭킹 감쇠를 조절하는 상수이며 일반적으로 60을 사용한다.)
  - 순위가 높은(rank 값이 작은) 문서일수록 가산 가중치가 높게 산정되며, 여러 쿼리 결과에 중복 포함될 경우 중첩 반영된다.
- ** RAG 파이프라인 결합**: RRF 연산 결과를 융합 점수 내림차순으로 정렬한 뒤, 상위 $N$개의 문서 청크만을 최종 RAG 프롬프트 컨텍스트에 주입하여 LLM이 정확하고 짜임새 있는 답변을 도출하도록 지원한다.

## 예시
- **RRF 융합 점수 계산의 구체 사례**:
  - 질문 $Q$로부터 변형 질문 $Q_1$, $Q_2$를 생성하여 벡터 검색 수행.
  - 문서 $A$가 $Q_1$ 검색에서 1위, $Q_2$ 검색에서 3위에 위치할 때 ($k=60$ 가정):
    $$Score(A) = \frac{1}{60 + 1} + \frac{1}{60 + 3} \approx 0.01639 + 0.01587 = 0.03226$$
  - 문서 $B$가 $Q_1$ 검색에서 2위, $Q_2$ 검색에는 미포함(기본 하위권 등으로 미노출)일 때:
    $$Score(B) = \frac{1}{60 + 2} \approx 0.01613$$
  - 여러 다각도 질문에서 일관되게 상위로 평가된 문서 $A$가 문서 $B$를 제치고 RAG 퓨전 리랭킹 1위로 선정되어 컨텍스트 최상단에 배치됨.

## 충돌
- **중복 문서 단순 유니언(Union) vs RRF 재정렬**:
  - 다중 쿼리를 날려 얻은 결과를 중복 제거(Set)만 거치고 그대로 평탄화하여 LLM에 넘기는 방식의 경우, 문서 간의 실질적인 유효 등급과 연관도 서열 정보가 완전히 소실된다. 또한, 무가치한 주변부 청크까지 전부 컨텍스트 창에 혼입되어 컨텍스트 노이즈를 증가시키고 모델의 환각 확률을 올리는 충돌이 발생한다. RAG 퓨전은 RRF 랭킹 가중으로 이를 제어함으로써 충돌을 해결한다.
